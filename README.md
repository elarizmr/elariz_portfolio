Welcome to my personal interactive 3D Web Developer portfolio! Built with **Next.js**, **React Three Fiber**, and **Three.js**, this application pushes the limits of modern web technologies by blending spatial WebGL computing and highly optimized frontend architecture.

> [!NOTE]
> Ensure hardware acceleration is enabled in your browser settings to experience smooth high-tier rendering.

## 🚀 Key Performance Architectures

1. **Invisible Semantic SEO Fallback:** Strategic `sr-only-seo` injections render fully visible semantic trees to native search engine crawlers without mounting heavy bundles.
2. **Asynchronous Shader Compilation:** Enforces `gl.compileAsync` during the preloading phase to compile materials asynchronously without blocking the main React thread.
3. **Baked Global Textures:** Optimized GPU compute overhead while maintaining visual depth.
4. **Adaptive Device Tiering:** Auto-detects device hardware specs to scale WebGL resolutions (`dpr`), antialiasing, and texture quality dynamically.
